Globex Finance — Supplier Portal API

Vendors look up their invoice details over a small read-only API.

Authentication

Every request must send the portal API key as a header:

X-Portal-Key: {{ api_key }}

Look up an invoice

GET /api/invoices/<reference>

Returns the invoice's reference, vendor, amount and status as JSON.

Example

curl -H "X-Portal-Key: {{ api_key }}" \
     http://localhost:3206/api/invoices/INV-20481
